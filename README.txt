ST. PETER'S SECONDARY SCHOOL – RWERA WEBSITE STARTER

CONTENTS
- index.html       Website page and content
- styles.css       Responsive navy, white and gold design
- script.js        Mobile menu, gallery lightbox, active navigation, current year, back-to-top
- assets/          Images extracted from the ZIP folder supplied in the chat

HOW TO PREVIEW
1. Extract the downloaded ZIP file.
2. Open the st-peters-website folder.
3. Double-click index.html to preview in a modern browser.
4. For best testing, use Visual Studio Code with the Live Server extension.

HOW TO EDIT
- Change page content in index.html.
- Change colours, typography and layout in styles.css.
- Change interactions in script.js.
- Images are referenced from the assets/ folder; keep filenames unchanged or update the matching paths.

DEPLOYMENT TO GITHUB PAGES
1. Create a GitHub repository (for example, st-peters-website).
2. Upload index.html, styles.css, script.js, README.txt and the assets folder to the repository root.
3. In the repository, open Settings > Pages.
4. Under Build and deployment, select Deploy from a branch, choose main and /(root), then Save.
5. Wait for GitHub Pages to publish the site and open the URL shown in Settings > Pages.
